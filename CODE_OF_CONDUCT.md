# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated.

To report unacceptable behavior, contact the maintainers privately through the organization's GitHub profile. Reports are handled confidentially.
